Competition-ready hardening layer for the RAW hackathon MVP.

- Application-wide React error boundary
- Sign-out action in the app shell
- PWA manifest and lightweight service worker

- Accessibility focus-visible treatment
- Demo-mode fallback retained when Supabase is not configured
